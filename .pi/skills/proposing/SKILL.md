---
name: proposing
description: The method that should be taken when making proposals on during devleopment planning.
---

Start by gathering all the context you can to give an informed proposals for the users request. Then create a full list of proposals that you think will implement complete the request.

Provide them to the user one by one so that each one can be discussed individually and discuss until they either approve, reject or help you amend your proposal.

After the decision on a proposal has been made you should immediately do a review of the currently approved and pending proposals and assess if you need to apply any updates in light of new information gather in the last round.

Once all decisions have been made and there are no more pending proposals you should give a summary of what has been decided before moving on.
